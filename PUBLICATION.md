# Publicación del proyecto

Este proyecto está en desarrollo. Los controles automáticos y sus resultados no constituyen una versión jugable aceptada; los fallos y las limitaciones vigentes están en HANDOFF.md y bugs.md.

El repositorio público se publica desde un árbol revisado, con un historial público independiente. El historial local completo se conserva. Los volcados de memoria (`*.mdmp`, `*.dmp`) no se publican: pueden contener datos del proceso ajenos al proyecto. Los informes de texto y manifiestos pueden referirse a esos archivos como evidencia local sin incluir su contenido.

Cada publicación registra el commit local de origen y los archivos omitidos. Las publicaciones posteriores actualizan ese árbol sin reescribir el historial público. No se envían por accidente otras ramas o el historial privado mediante `--all` o `--mirror`.

Los datos GIS y builds grandes conservados fuera de Git se identifican por sus manifiestos. Reconstruir requiere el entorno y herramientas indicados en README.md, los datos originales autorizados y una instalación local de DayZ/DayZ Tools. Publicar este código no concede derechos sobre recursos de terceros.
