# EV112 — preparación de navegación F
**Preparación abierta, sin generación ni sonda F de navegación.**
El terreno F ya pasó4749 controles físicos. E tiene NM9 propia verificada;
no se hereda esa aceptación para F.

La primera propuesta de líneas cruza celdas próximas al agua. La segunda criba
numérica encontró líneas secas, pero Fable5.1 detectó que floor solo comprobaba
una banda cuando coincidían con líneas de rejilla. Esas coordenadas son hipótesis,
no referencias aceptadas. Se conservan ambas salidas y la revisión SOUND-with-fixes.
El plan revisado exige ambas bandas, preparador explícito37+8 consultas, marcas
únicas E/F, hashes completos, taxonomía previa y una puerta independiente de
cobertura real. Todo ello queda pendiente de implementar/probar antes del motor.

Los artefactos aquí son descubrimiento y diseño. No acreditan objetos3D libres,
locomoción, IA, navegación global ni aceptación visual. No se ha cambiado terreno,
agua, protecciones ni parámetros para obtener una ruta válida.
