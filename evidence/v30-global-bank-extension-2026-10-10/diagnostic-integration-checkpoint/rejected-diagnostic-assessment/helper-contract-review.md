## Erratum — topology helper input coordinates

This retracts the earlier statement that the `exposed_topology` call contract was compatible. The caller in `recovery-v2/assess_rejected_diagnostic.py:408` passes `bctx` and `hctx`, both 15x15 local crops, to `helper.exposed_topology(...)`. The helper at `diagnostic-polish-consumer-v1/verify_polished_diagnostic.py:669-726` iterates global face cell coordinates and indexes these arrays through `ev87.corner_values`; a real v3 run therefore raised an out-of-range index (862) before writing its report. The caller must supply full-grid `base_h` and `h_full`, or the helper must explicitly translate and clip global coordinates to the local window. No fix is reviewed here.

Corrected verdict: the prior read-only review was incomplete and did not establish overall helper compatibility. In addition to the already known `verify_preflight` path/key error, this topology caller/helper coordinate mismatch blocks the run. This erratum preserves rather than replaces the prior note; it is based on the reported v3 failure and cited source locations, with no new tests or execution by this reviewer.
