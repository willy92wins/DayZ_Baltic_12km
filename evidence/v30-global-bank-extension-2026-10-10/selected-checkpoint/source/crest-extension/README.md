# EV93 crest extension v2 (pool + selector + independent consumer)

This directory contains a no-solver authoring stage, a separate window selector, and an independent global consumer. It does not modify the frozen layer-1 artifacts or write an accepted terrain candidate during authoring. The author is deliberately pinned to the one reviewed source report that failed exactly the physical and visible support-hole gates; this is provenance for quarantine only, never a PASS.

`author_reused_directions.py --execute --source-global-report ... --source-global-sha256 ...` derives the 228 frozen one-axis directions into a resumable quarantine pool. The 600-second budget, append-only ledger, atomic target writes, source pins, and fail-closed resume checks remain in force. Each target ends as `derived_quarantined` or `rejected_policy`; shape metrics in target rows are diagnostic only. Authoring does not compose heights, invoke a solver, or create `candidate-terrain.npz`.

A complete run writes `receipt.json`, `targets.jsonl`, and `compound-pool.json` with 340 references to the original legacy accepted result rows and 228 references to the new quarantine target rows. `unit_id` is namespaced by `origin` (`legacy:<qid>` / `crest:<qid>`); `source_qid` ties both to their original source artifacts. The pool status `AUTHORED_QUARANTINED` does not imply local validity or selection.

The separate selector evaluates all 568 units and decides whole-window retention/exclusion based on full local gates and compiled physical/visible support-hole contributions. It owns candidate composition and must publish an exhaustive `selection.json` and exact candidate only after its execution is reviewed. The independent `verify_composite.py` must then reconstruct every source direction, recalculate one-axis alphas and float32 casts, validate the selector’s exhaustive classification/ownership, rerun local/global physical and water contracts on the selected candidate, and recompute the ANY population as a diagnostic. It must not import the author or selector. A successful incremental status does not close inherited map/render defects.

`--self-test` runs analytic scalar-policy and cardinal fixtures, append-only ledger round-trip, and a synthetic 568-reference compound-pool fixture. These are implementation checks only; they do not authorize author execution or replace the independent full consumer.
