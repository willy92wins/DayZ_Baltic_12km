# EV93 crest extension (source only)

This folder contains a no-solver derivation stage and an independent composed consumer. It does not alter the frozen layer-1 authoring inputs. Do not run `author_reused_directions.py --execute` until the integrator supplies the final PASS report for `fairing-layer1`.

The author accepts one exact global PASS report path and SHA, then pins the execution plan, source inventory, B, legacy composite, prepared ledger, direction artifacts, policy, and frozen consumers. The default output is resumable: `run.json` fixes the run identity; `ledger.jsonl` appends a `started` and terminal `target` event per finished row; `targets/window-NNNN.json` is written atomically and never overwritten. A prior start with no terminal result is pending and may be resumed only after all pins revalidate. A terminal row is hash-checked and skipped. Unexpected errors record `INCOMPLETE` and stop; they are never classified as geometry rejections. The 600-second budget is checked between rows, so a currently executing row may finish just beyond the deadline. Incomplete runs have no final candidate. A completed candidate is published only after all 228 rows are terminal and the full read set is rehashed.

The extension receipt uses `ev93.crest-extension.receipt.v2`; `AUTHORED_PENDING_COMPOSITE_CONSUMER` is not a PASS. It records the 228 row references, append-only ledger hash, execution-plan/source/policy pins, candidate hash, and zero new solver calls. Rows either preserve a source rejection (`rejected_policy` / `rejected_local_shape`) or carry one scalar alpha derived from the exact reused direction (`derived_pending_composite_consumer`). The original 340 accepted rows remain in the frozen legacy composite and are not given fabricated rejection provenance.

`verify_composite.py` independently reloads frozen EV92 artifacts, reconstructs the legacy 340-window result, re-derives every reused alpha from B and the original direction, checks the ledger/receipt and node ownership, rebuilds the exact composite, reruns local geometry checks on that composition, and invokes the frozen global geometry/water contract. It does not import the author. Global inherited defects remain open even if its incremental gates pass.

Local fixtures exercise the scalar helper, zero-axis rejection, float32 focus check, immutable ledger round trip, missing terminal records, missing final event, composition, and duplicate node ownership. They do not substitute for the full consumer or authorize author execution.
