Usage: C:\Program Files (x86)\Steam\steamapps\common\DayZ Tools\Bin\NavMeshGenerator\NavMeshGenerator_x64.exe [options] save_path
Tool for generating navigation meshes for Enfusion engine.

Options:
  -?, -h, --help                         Displays this help.
  -v, --version                          Displays version information.
  -c, --console                          Run console application.
  -r, --remote                           Run as remote client generator.
  -k, --kill                             Kill server when the generation is
                                         completed.
  -e, --reconnect <reconnect>            Reconnect count.
  -a, --server_address <server_address>  Numeric IP address of the server.

Arguments:
  save_path                              Save path of the resulting navigation
                                         mesh pathgraph.
